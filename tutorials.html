Tutorials

Getting Started

Welcome to the Lung TFDB! This tutorial will guide you through the basic features of our database.

  1. Navigate through the different sections using the navigation bar at the top of the page.
  2. Each section provides a unique set of tools and data for analyzing transcription factors in lung cancer.
  3. Use the search and filter options to find the specific information you are looking for.

How to Search

Our search functionality is designed to be intuitive and powerful.

  • Gene Search: In sections like "Mutations" and "Expression," you can search for a specific gene by entering its name in the search box.
  • Filter by Dataset: You can filter the data by selecting a specific dataset from the dropdown menu.
  • Advanced Filters: Some sections may offer advanced filtering options to further refine your search results.

Analyzing Data

Lung TFDB provides several tools for data analysis.

  • Survival Analysis: In the "Survival" section, you can generate Kaplan-Meier plots to visualize the impact of TF expression on patient survival.
  • Expression Analysis: In the "Expression" section, you can compare TF expression levels between tumor and normal tissues using violin and box plots.
  • scRNA-seq Analysis: In the "scRNA-seq" section, you can explore TF expression at the single-cell level using UMAPs, feature plots, and violin plots.

Downloading Data

You can download data for offline analysis.

  1. Go to the "Download" section.
  2. Select the dataset you want to download.
  3. Click the "Download" button to save the data to your computer.
