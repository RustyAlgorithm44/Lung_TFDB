Tutorials

This tutorial shows how to generate a Kaplan-Meier survival plot for a transcription factor.

1

Navigate to the Survival page from the header menu.

2

Enter the official gene symbol for your transcription factor of interest (e.g., "SOX2") into the "Enter Gene" input box.

A list of available genes will appear as you type.

3

Select the desired lung cancer dataset (e.g., TCGA-LUAD) from the dropdown menu.

4

Click the "Analyze" button to generate the plot.

The Kaplan-Meier plot will be displayed, showing survival probability for patients with high and low expression of the gene. A p-value is provided to indicate statistical significance.

This tutorial explains how to compare a TF's expression between tumor and normal tissues.

1

Navigate to the Expression page.

2

Enter the gene symbol (e.g., "NKX2-1") in the search box.

3

Select a dataset to compare expression levels within.

4

Click the "Submit" button.

Box plots or violin plots will be shown, illustrating the expression distribution in tumor versus normal samples.

This tutorial covers how to visualize mutation data for one or more TFs.

1

Navigate to the Mutations page.

2

Enter one or more gene symbols separated by commas (e.g., "TP53,KEAP1,NFE2L2") into the text area.

3

Select the cancer type (e.g., LUAD) from the dropdown.

4

Click "Generate OncoPlot".

An OncoPlot will be generated, displaying the mutation landscape of the selected genes across the patient cohort. Different colors represent different mutation types (e.g., missense, nonsense, frameshift).

This tutorial demonstrates how to explore TF expression at single-cell resolution.

1

Navigate to the scRNA-seq page.

2

Select a dataset from the "Choose Dataset" dropdown menu (e.g., "Maynard2020_Lung").

3

In the "Choose one or more gene symbols" input, type a gene name (e.g., "A2M") and click on it from the dropdown to add it. You can add multiple genes.

Selected genes will appear as tags below the input box.

4

Choose an "Annotation Type" to label the cell clusters in the UMAP plot (e.g., "Default annotation").

5

Click the "Search" button to generate the plots.

Please be patient, as scRNA analysis can take some time.

Various plots will be displayed:

  • UMAP Dim Plot: Shows cell clusters based on the chosen annotation.
  • Feature Plot: Overlays the expression of your selected gene(s) onto the UMAP plot.
  • Violin Plot: Compares the expression of your gene(s) across different cell clusters.
  • Dot Plot: Shows the percentage of cells expressing the gene(s) and the average expression level in each cluster.
